X-Wallet V15.3.1 (2026-11-21)
=============================
Personal Finance Manager (PWA) / مديرك المالي الشخصي

أبرز تحديثات V15.3.1:
1. توحيد شامل 100% للصف الثاني (الارتفاع الثابت 48px، التصميم، الحواف، والخطوط والمربعات الداخلية) في السجل، التحليل، المحفظة، الالتزامات، المزيد، وكافة الأقسام الداخلية للمزيد وكشف الحساب.

4. حذف اسم المطور من جميع بطاقات التعريف في التطبيق.
