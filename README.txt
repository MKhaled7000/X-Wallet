X-Wallet V15.3.4 (2026-11-21)
=============================
Personal Finance Manager (PWA) / مديرك المالي الشخصي

أبرز تحديثات V15.3.4:
1. تغيير أيقونة الفلتر في قائمة الاختصارات السريعة إلى أيقونة قمع واضحة وموحدة.
2. إصلاح اتجاه نص نافذة التأكيد (RTL) وإصلاح زر «تأكيد» لحذف حركة سداد البطاقة أو الالتزام فعلياً وإرجاع الرصيد والمديونية فوراً.
3. إتاحة حذف أي بطاقة (حتى لو عليها عمليات أو سدادات) بعد رسالة تأكيد واضحة تحذف البطاقة وكل سجلاتها المرتبطة.
4. إضافة «الالتزامات» فعلياً لقائمة الاختصارات السريعة وإعداداتها وتفعيلها تلقائياً.
5. صفحة المحفظة: توحيد ارتفاع صفوف الحسابات والبطاقات (38px)، وإضافة زر القلم (✎) لتعديل الحسابات/البطاقات، وترتيب الأيقونات من اليمين لليسار: ＋ ← ✎ ← ⇅ ← 🗑 ← 👁.
