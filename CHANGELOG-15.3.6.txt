X-Wallet V15.3.6: سجل الملفات
============================
قاعدة الرقعة: X-Wallet-V15.3.5-patched.zip. ملفات الجذر محفوظة دون مجلد إضافي.

ملفات جديدة
------------
google-drive.js
- GIS token client بصلاحية drive.file فقط، اختيار الحساب، رفض الصلاحيات
  الناقصة، ومعالجة إغلاق النافذة وانتهاء الرمز و401.
- الرمز في الذاكرة فقط. رفع نسخة مشفرة جديدة عبر resumable upload لدعم
  الملفات الكبيرة، وقراءة تحقق من الملف المرفوع.
- تنزيل أحدث نسخة منشأة بهذا المسار، ورفض الملف غير المشفر، وتأكيد الاستبدال.

financial-tools.js
- واجهات إدارة الأهداف والميزانيات والقواعد الشهرية.
- تقدم الأهداف وحركات ادخار/سحب للتتبع دون تحريك الحسابات.
- مجاميع الميزانيات من تعريف مصروفات السجل، مع تحديد الشهر والقسم.
- إضافة وتعديل وإيقاف وحذف القواعد مع تحقق الحساب والمبلغ واليوم والفترة.
- كل تغيير عبر runCriticalWalletAction، مع نقطة استعادة وحفظ متحقق منه،
  وسجل تدقيق، والتحقق من أن العنصر لم يتغير أثناء الحفظ.

ملفات معدلة
------------
app.js
- استبدال واجهة ربط السكريبت بإعداد OAuth Client ID وشرح الأصل والصلاحية.
- إبقاء GitHub خياراً اختيارياً، وزر نسيان جلسة Google محلياً.
- حذف مولد كود Apps Script. مسار الإقلاع والحماية السابق لم يتغير.

cloud-backup.js
- حذف فحص خادم السكريبت ومسار تنزيله، والتوجيه إلى وحدة Google الجديدة.
- طلب تفويض Google من ضغطة الزر قبل خطوات التشفير، دون تخزين الرمز.
- إبقاء اشتراط تشفير الرفع، ومسارات GitHub وتقسيمه وفحصه كما هي.

sync.js
- حذف مُصدّر Google القديم بمسارات السكريبت والرمز الملصوق والمشاركة البديلة.
- ربط الواجهة بمعرّف العميل، ومنع إعادة قيم الربط القديم عند الاستعادة.
- نقاط الاستعادة والحفظ الحرج والتراجع والتحقق السابقة محفوظة.

storage.js
- إزالة قيم السكريبت والسر والرمز القديم والبريد من الحالة الفعالة بعد قراءتها.
- حذف تحديث حقل البريد المتقاعد. لا تغيير لاسم IndexedDB أو آلية الترحيل.

settings.js
- حذف ربط حقل البريد المتقاعد فقط.

components.js
- دعم زر الرجوع لإغلاق أدوات مالية بعد إغلاق أي حوار أعلى منها.

quick-entry.js
- إضافة aria-pressed ووصف الحالة لزر التكرار الشهري.
- عرض صف القسم كشبكة عند ظهوره، مع إبقائه مخفياً للتحويل.
- عنوان للنص الكامل للقسم الطويل. لا تغيير لمنطق الحفظ أو حسابات المعاملات.

styles.css
- تثبيت عمود قيمة القسم ومحاذاته مع بقية القيم، مع الحفاظ على ترتيب العربية.
- عرض مقيد لثلاثة أزرار نوع المعاملة على الهواتف الصغيرة.
- نفس حجم ووزن الخط لملخصي السجل والمحفظة.
- إضاءة واضحة لزر التكرار النشط وأنماط RTL لواجهات الأدوات وإعداد الربط.

index.html
- بند أدوات مالية وحاويته، وحالة وصول لزر التكرار.
- تحميل GIS ووحدتي Google والأدوات الجديدتين، ورفع مراجع الأصول إلى 15.3.6.

core.js
- رقم إصدار التطبيق 15.3.6 فقط، دون تغيير مفاتيح البيانات.

sw.js
- كاش ومراجع أصول 15.3.6، مع الوحدتين الجديدتين ضمن الـapp shell.
- لا يجري تخزين ردود Google Drive أو رموز التفويض في كاش الخدمة.

version.json
- رقم الإصدار وملاحظات إصدار عربية جديدة.

README.txt
- إعداد Google Cloud وClient ID والأصل وTesting وبريد الاختبار.
- حدود النطاق والجلسة والتشفير والاستعادة والنسخ القديمة والأدوات.
- تنبيه أن أي نشر Apps Script قديم لا يتوقف من تلقاء نفسه.

TEST-PLAN.txt
- الاحتفاظ باختبارات قبول إصلاحات 15.3.5، واستبدال اختبارات السكريبت
  باختبارات OAuth وإضافة اختبارات RTL والأدوات وفشل الحفظ والرجوع.

ملف محذوف
----------
GoogleDrive-AppsScript.gs: لم يعد التطبيق يستخدم Apps Script.

ملفات مالية حساسة لم تتغير بايتاً واحداً
----------------------------------------
cards.js، transactions.js، financial-engine.js، backup.js، migration.js،
single-currency.js. كذلك بقيت وحدة management.js ومحرك التكرار القديم كما هما.

حدود الاختبار
--------------
فحوص الصياغة لكل JS والسكربتات الكلاسيكية بالترتيب، وفحوص وحدات معزولة بوهم
الواجهة والشبكة، ومعاينات ثابتة ببيانات وهمية. لم يشغل التطبيق كاملاً ولم
يُسجل الدخول إلى Google ولم تُختبر بيانات المستخدم أو الترحيل الحقيقي.
